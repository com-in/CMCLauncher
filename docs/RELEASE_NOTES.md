# CMCLauncher 0.9.4

## Highlights

- Add integrated frpc downloads, INI/TOML configuration management, process controls, and runtime logs. Configurations are copied into the launcher directory, with support for multiple profiles and folder imports.
- Add schematic file management for supported modded instances, including expandable folders, import, export, rename, and delete actions.
- Expand community resource filters with a dedicated drawer, persistent search filters, pagination, and direct page navigation.
- Streamline vanilla installation into version selection followed by installation options.
- Add compact theme-colored notifications, inline deletion confirmations, and more detailed DEBUG logging.
- Load interface translations from editable JSON language packs. English (`en_us`) is the default; saved language preferences and Chinese translations remain available.
- Improve dark-theme colors, dropdowns, navigation animations, and narrow-window layouts.
- Standardize product naming and source formatting, and update the English and Chinese documentation.

## Download

Download `CMCLauncher-0.9.4-win-x64.zip`, extract the entire archive, and run `CMCLauncher.exe`. The archive includes the .NET and Windows App SDK runtimes. Java, Minecraft files, and frpc are downloaded or imported separately.
