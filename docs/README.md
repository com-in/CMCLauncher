# CMC Launcher

CMC Launcher 是 Minecraft Java 版原生 Windows 启动器，使用 WinUI 3 构建。官网页面位于 `index.html`，图片、样式和交互脚本均为静态文件，不依赖服务端。

## 部署

可直接用 GitHub Pages 发布：在仓库设置中将 Pages 来源设为 `Deploy from a branch`，分支设为 `main`，目录选择 `/docs`。

GitHub 仓库目前没有正式 Release。发布版本后，官网的下载入口会指向 GitHub Releases。
