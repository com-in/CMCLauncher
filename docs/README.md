# CMCLauncher

CMCLauncher is a native Windows launcher for Minecraft Java Edition, built with WinUI 3. The website in `index.html` is static and does not require a server-side component.

## Deployment

Deploy with GitHub Pages by setting the source to `Deploy from a branch`, selecting the `main` branch, and choosing the `/docs` folder.

The website's download links point to GitHub Releases.
